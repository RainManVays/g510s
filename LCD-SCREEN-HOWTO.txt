КАК РАБОТАЕТ ЭКРАН (LCD) В g510s
=================================


АРХИТЕКТУРА: КОЛЬЦЕВОЙ СПИСОК
──────────────────────────────

 ЖЕЛЕЗО                         g510s (процесс)
 ──────                         ───────────────

                          ┌─────────────────────────────────┐
                          │  Кольцевой двусвязный список    │
                          │  lcdlist_t                      │
                          │                                 │
                          │  ┌──────────┐                   │
                          │  │  tail    │  ← всегда один,   │
                          │  │  (ЧАСЫ)  │    не удаляется   │
                          │  │  lcd->buf│                   │
                          │  └────┬─────┘                   │
                          │  ▲    │  g510s-clock.c рисует   │
                          │  │    │  цифры в этот буфер     │
                          │  │    ▼                         │
                          │  ┌──────────┐                   │
                          │  │ client A │ ← подключился     │
                          │  │  lcd->buf│   первым по TCP   │
                          │  └────┬─────┘                   │
                          │  ▲    │                         │
                          │  │    ▼                         │
                          │  ┌──────────┐                   │
                          │  │ client B │ ← подключился     │
                          │  │  lcd->buf│   вторым (head)   │
                          │  └────┬─────┘                   │
                          │       │                         │
                          │       └──────── (→ tail)        │
                          │                                 │
                          │  current ──▶  [кто-то из них]  │
                          └────────────────┬────────────────┘
                                           │  каждые 50мс
                                           │  update_function()
                                           ▼
 ┌──────────────┐            writePixmapToLCD(current->lcd->buf)
 │  LCD экран   │ ◀──────────────────────────────────────────────
 │  клавиатуры  │
 └──────────────┘


КТО И КАК ПИШЕТ В БУФЕР
────────────────────────

 ┌──────────────────────────────────────────────────────────┐
 │  tail (ЧАСЫ)                                             │
 │                                                          │
 │  g510s-clock.c::digital_clock()                         │
 │  вызывается update_function раз в минуту                 │
 │  рисует "HH:MM" и (опц.) дату в lcd->buf                │
 └──────────────────────────────────────────────────────────┘

 ┌──────────────────────────────────────────────────────────┐
 │  TCP клиент (g15stats, g15mpd, любое приложение)        │
 │                                                          │
 │  1. подключается к 127.0.0.1:15550                      │
 │  2. получает HELLO от g510s                              │
 │  3. в цикле шлёт кадры:                                 │
 │     'G' → 6880 байт (packed pixels)                     │
 │     'R' → 1048 байт (raw)                               │
 │     'W' → 865 байт (wbmp)                               │
 │  4. g510s кладёт кадр в lcd->buf                        │
 │  5. отключился → узел удаляется из списка               │
 └──────────────────────────────────────────────────────────┘


КНОПКИ L И НАВИГАЦИЯ
─────────────────────

  L1 нажата:  current = current->prev  (листает назад по кольцу)

  Порядок листания при 2 клиентах:

  [ЧАСЫ/tail] → L1 → [client B, head] → L1 → [client A] → L1 → [ЧАСЫ/tail]

  ┌────────────────────────────────────────────────────────┐
  │  Кнопки на экране                                      │
  │                                                        │
  │  Показан экран ЧАСОВ (current == tail):               │
  │    L2 → 12ч ↔ 24ч формат                             │
  │    L3 → показать / скрыть дату                        │
  │    L4, L5 → ничего не делают                          │
  │                                                        │
  │  Показан экран КЛИЕНТА (current != tail):             │
  │    L2, L3, L4, L5 → нажатие пересылается клиенту     │
  │                      по TCP (клиент сам решает,       │
  │                      что с ним делать)                │
  └────────────────────────────────────────────────────────┘


ИТОГ
────

  current — это указатель "что сейчас на экране".
  tail    — это часы, они всегда есть.
  Всё остальное — внешние приложения, подключённые по TCP.
  Новый клиент появляется в начале кольца (head),
  L1 листает по кольцу.

  Прямо сейчас, скорее всего, только часы —
  никакие TCP-клиенты не подключены (head == tail).
